locus 01.01
song
bar
reference

y(t), the sound

Runs once per sample for every note that's playing.

t
seconds since the note started
f
note frequency in Hz
m
note number (69 = A4)
v
velocity, whatever hit(n) returned (0 to 1)
d
note length in seconds
i
sample index since the note started
sr
sample rate

hit(n)

Runs every step (a 16th note). Anything above 0 plays, and the value becomes the velocity.

n
step in the loop
s
step in the bar, 0 to 15
bar
bar number
k
which chord we're on

note(n)

The note number to play. A [list] plays all of them.

root
root of the current chord, octave 2
ch(j)
j-th chord tone counting up from octave 3
deg(d)
d-th degree of the scale counting up from octave 4
euclid(k, len, s)
k hits spread evenly over len steps (also in hit)

functions

saw sqr tri
waves with period 1, so saw(f*t). sqr(x, w) takes a pulse width
osc(hz)
phase that follows a moving frequency: sin(tau*osc(hz))
lp hp bp
filters: lp(x, hz) or lp(x, hz, q)
noise(i)
hash noise, same output for the same i
ad(t, a, d)
attack then exponential decay
hold(x, hz)
sample and hold
crush(x, bits)
bit crusher

syntax

+ - * / % ^, comparisons give 1 or 0, && || !, a ? b : c, bit ops & | << >>. [a, b, c][i] picks from a list and wraps around. name = ... on its own line makes a variable, the last line is the result. // starts a comment.
